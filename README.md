# carburanti-dati

Copia giornaliera dei dati open data del Ministero delle Imprese e del Made in Italy
(Osservaprezzi Carburanti, licenza IODL 2.0): anagrafica degli impianti e prezzi alle 8.

Serve all'app "Lungo il percorso", perché il sito del Ministero non permette ai siti web di scaricare i file direttamente.
I file sono aggiornati ogni giorno da GitHub Actions e non vengono modificati.

Fonte: https://www.mimit.gov.it/it/open-data/elenco-dataset/carburanti-prezzi-praticati-e-anagrafica-degli-impianti
